05 - Inicio do login com Google (cabecalhos saneados)
======================================================

Projeto: https://oauth-gabriel-fortunato.pages.dev
Captura feita na implantacao de producao, com Preserve log ativado.
Valores transitorios substituidos por [REMOVIDO].

Pedido
------
GET /oauth/login/google HTTP/2
Host: oauth-gabriel-fortunato.pages.dev

Resposta
--------
HTTP/2 302
cache-control: no-store
set-cookie: __Host-oauth-tx=[REMOVIDO]; Path=/; HttpOnly; Secure;
            SameSite=Lax; Max-Age=600
location: https://accounts.google.com/o/oauth2/v2/auth
          ?client_id=[REMOVIDO]
          &redirect_uri=https%3A%2F%2Foauth-gabriel-fortunato.pages.dev
                        %2Foauth%2Fcallback%2Fgoogle
          &response_type=code
          &state=[REMOVIDO]
          &code_challenge=[REMOVIDO]
          &code_challenge_method=S256
          &scope=openid+email+profile
          &nonce=[REMOVIDO]

state, code_challenge e nonce tinham 43 caracteres Base64URL cada
(32 bytes de crypto.getRandomValues, sem preenchimento).

Conferencias (secao 15.2 do roteiro)
------------------------------------
[x] o estado HTTP e 302
[x] a resposta cria __Host-oauth-tx
[x] Location aponta para o Google
[x] response_type=code esta presente
[x] code_challenge_method=S256 esta presente
[x] a URL de retorno e a URL pages.dev exata
[x] Client Secret e code_verifier estao ausentes
[x] somente os escopos openid, email e profile foram solicitados
